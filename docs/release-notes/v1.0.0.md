The first release of Calibrate 3D Printer: ready-to-print calibration G-code for any FDM
printer, without a slicer. Try the page right in the browser:
https://alexalesha.github.io/Calibrate3dPrinter/

- **Ten tests** with time, grams, a preview and a helper that turns "the best line" into the
  number for your slicer profile.
- **Your own G-code sets the printer up:** start and end code and firmware are taken from a
  file sliced by OrcaSlicer, ElegooSlicer, Bambu Studio, PrusaSlicer, SuperSlicer or Cura.
- **Checked on a real printer:** for the Elegoo Centauri Carbon the output is byte for byte
  the G-code that was printed and works. 14 printer profiles, 5 materials, nozzles 0.2-0.8.
- **Two editions, the same G-code:** Electron (setup or portable) and Python with a Qt window
  (setup or portable zip). A G-code check reads every file back before you print it.

| File | What it is |
|---|---|
| `Calibrate3dPrinter-Electron-1.0.0-Setup.exe` | Electron edition, installer |
| `Calibrate3dPrinter-Electron-1.0.0-Portable.exe` | Electron edition, no install |
| `Calibrate3dPrinter-1.0.0-setup.exe` | Python edition, installer |
| `Calibrate3dPrinter-1.0.0-portable.zip` | Python edition, unzip and run |

Первый выпуск «Калибровки 3D-принтера»: готовые калибровочные G-code для любого
FDM-принтера без слайсера. Страницу можно открыть прямо в браузере:
https://alexalesha.github.io/Calibrate3dPrinter/

- **Десять тестов** со временем, граммами, предпросмотром и помощником, который превращает
  «лучшую линию» в число для профиля слайсера.
- **Свой G-code настраивает принтер:** начальный и конечный код и прошивка берутся из файла
  OrcaSlicer, ElegooSlicer, Bambu Studio, PrusaSlicer, SuperSlicer или Cura.
- **Проверено на настоящем принтере:** для Elegoo Centauri Carbon результат байт в байт
  совпадает с G-code, который напечатан и работает. 14 профилей принтеров, 5 пластиков,
  сопла 0.2-0.8.
- **Две версии, одинаковый G-code:** Electron (установщик или portable) и Python с окном Qt
  (установщик или portable zip). Проверка G-code перечитывает каждый файл перед печатью.

Файлы: Electron - `...-Electron-1.0.0-Setup.exe` (установка) и `...-Electron-1.0.0-Portable.exe`
(без установки); Python - `Calibrate3dPrinter-1.0.0-setup.exe` (установка) и
`Calibrate3dPrinter-1.0.0-portable.zip` (распаковать и запустить).
